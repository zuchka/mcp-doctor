## Accepted beta limitations

- One deterministic remote-inspection tool; no hosted evals, artifacts, Scope Lab, local
  paths, process execution, or downstream credentials.
- Targets are exact operator-approved HTTPS URLs on port 443 and must resolve only to global
  addresses.
- Application-level concurrency is global. Per-principal throttling is a Horizon control.
- Direct local HTTP is for loopback development only.
- The older full conformance suite is useful diagnostic evidence but not a public-launch pass.

## Interview notes

- F-002: a managed deployment exposed a real dependency/API boundary that local transitive
  imports had hidden.
- F-003/F-004: “run conformance” is not a binary checkbox when the standard and its fixtures
  are moving; record the exact runner, dated suite, and why a failure is or is not relevant.
- F-005: annotations and application-level auth are not network controls. The public security
  story is only complete when gateway behavior is tested on the real URL.
- F-006: OAuth marketing can hide a second identity-verification step that matters during a
  live onboarding or interview demo.
- F-010: default-branch entrypoint validation can block the safest preview-first path when a
  pull request introduces the entrypoint itself.
- F-011/F-012/F-013: the managed gateway supplied the expected auth and Host/Origin boundary,
  and useful request attribution survived privacy-preserving payload logging settings.
